# 🏠 EstateFlyer AI - Profesionálny Marketing pre Realitárov

Moderná webová aplikácia vytvorená s **React**, **Tailwind CSS** a **Vite** pre rýchle vytvárame profesionálnych marketingových materiálov pre realitných maklérov.

## ✨ Hlavné Funkcie

### 1. **Ponukový List (PDF Preview)**
- 🎨 Dizajnový náhľad A4 dokumentu
- 📊 Tabuľka kľúčových parametrov (Cena, Výmera, Počet izieb, Lokalita, Stav)
- 📝 Pútavý popis nehnuteľnosti
- ⭐ TOP 5 výhod s ikonami
- 📞 Kontakt na makléra s možnosťou úpravy
- 🖨️ Funkcia tlače a stiahnutia PDF

### 2. **Príspevky na Sociálne Siete**
- 📱 Text optimalizovaný pre Instagram a Facebook
- 😊 Automatické pridávanie emoji
- 🎯 Výzva na akciu (CTA)
- #️⃣ Relevantné hashtagy
- 📋 Tlačidlo na kopírovanie textu

### 3. **E-mailové Kampane**
- 📧 Predmet e-mailu + telo
- 🎯 Navrhnuté na odoslanie do databázy záujemcov
- 💼 Profesionálny formát
- 📋 Tlačidlo na kopírovanie

## 🚀 Inštalácia a Spustenie

```bash
# Klonuj repozitár
git clone https://github.com/supekmilan77-maker/EstateFlyer-AI.git
cd EstateFlyer-AI

# Nainštaluj závislosti
npm install

# Spusti vývojový server
npm run dev

# Otvri v prehliadači
# http://localhost:3000
```

## 📋 Technologický Stack

- **React 18** - Komponentový framework
- **Tailwind CSS** - Utility-first CSS framework
- **Vite** - Rýchly build tool
- **lucide-react** - Ikony
- **JavaScript ES6+** - Moderný JavaScript

## 🎯 Ako Používať

1. **Vložte text inzerátu** - Zadajte popis nehnuteľnosti do textového poľa
2. **Vyberte tón reči** - Zvoľte si z troch možností:
   - ⚡ Naliehavý / Exkluzívny
   - ✨ Moderný / Priateľský
   - 👑 Elegancia / Luxus
3. **Vygenerujte balík** - Kliknite na tlačidlo "Vygenerovať marketingový balík"
4. **Upravte a zdieľajte** - Upravte generovaný obsah a zdieľajte ho s klientami

## 📄 Generovanie Obsahu

### Parsing Inzerátu
Aplikácia automaticky parsuje text inzerátu a identifikuje:
- 💰 Cenu nehnuteľnosti
- 📐 Výmeru v m²
- 🛏️ Počet izieb
- 📍 Lokalitu
- 🏗️ Stav nehnuteľnosti

### AI Generovanie
Na základe zvoleného tónu sa generuje:
- **Ponukový list** - Profesionálny dizajn s pútavým popisom
- **Sociálne príspevky** - Optimalizované pre Instagram a Facebook
- **E-mailové kampane** - Formálny text na komunikáciu s klientmi
